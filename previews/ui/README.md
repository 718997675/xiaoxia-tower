# UI 回稿投放目录（第 22 轮）

把外部模型出的界面设计稿放这里，然后跑：

```bash
python3 tools/check_ui_art.py previews/ui/
```

脚本会检查（依据 `docs/04` §4 / `docs/07` §4 / `docs/12` §4）：

| 检查 | 判定 |
|---|---|
| 尺寸 | 界面稿必须是 **480×270 的整数倍**（1920×1080 = 4×）；图标稿用 `--type icon` |
| 调色板越界 | 超出 24 色锁定板的像素占比（WARN > 2% / FAIL > 10%） |
| 半透明 | alpha ∈ (1,254) 的像素占比（像素风要求 0） |
| 抗锯齿柔边 | 骑在两个调色板色块交界上的过渡像素占比 |
| 纯白 | `#FFFFFF` 占比（只该用于闪白） |

报告写到 `docs/ui-art-check-report.json`。

**出图提示词**：`docs/19-UI界面设计规格与外发提示词.md`，整段复制用 `previews/ui-prompts-pack.md`。

> 口径提醒：按 `docs/03` §4，外部模型出的 UI 图属**参考稿**——像素风要逐像素可控才能入库，
> 最终资源仍走程序化像素链路（`tools/build_icons.py` 等）。本目录的体检结果是**返工依据**，不是入库闸门。

> 本目录在 `previews/` 内，受 `previews/.gdignore` 保护，Godot 引擎不会扫描其中的 PNG。

## 回稿标准流程（第 24 轮起）

外部模型出的图先按 `*.png` 归档为 `<名字>_original.png`（保留未处理证据），再吸附到 24 色锁定板：

```bash
# 单张
python3 tools/snap_ui_palette.py previews/ui/01-mainmenu_original.png \
    -o previews/ui/01-mainmenu_palette24.png

# 批量 + 接着体检（自动跳过 *_original.png / *_palette24.png，可反复跑）
python3 tools/snap_ui_palette.py previews/ui/ --then-check
```

吸附脚本从 `docs/asset-manifest-pixel.json` 取色，把 JPEG / 截图在硬边处产生的中间色
压回冻结色板，**保留 alpha**（② HUD 透明背景需要）、输出恒为 PNG、几何尺寸不变。
输出里的「实质越界」= 距离板色 > 40 的像素（与体检同阈值），「压缩微调」是 JPEG
造成的极轻微色偏，两者分开统计，别把后者误读成改动画面。

**出图时务必**：在生成平台手动选 **16:9 画幅**并导出 **PNG**。提示词里写 1920×1080
不生效（第 24 轮两张回稿分别出了 1024×1024 与 1280×1280 方图），方图会稳定触发
`size_rule` FAIL。参考稿可豁免尺寸，正式资源必须是 480×270 的整数倍。

**第 24 轮已收编**（模型：GPT-Image-2.0，均属参考稿）：

| 回稿 | 原始 | 吸附版 | 吸附后 |
|---|---|---|---|
| ⓪ 风格锚点板 | `00-anchor-gpt-image2_original.png` | `00-anchor-gpt-image2_palette24.png` | 越界 0% / 柔边 0% / 纯白 0.36%，仅剩尺寸 |
| ① 主菜单 | `01-mainmenu-gpt-image2_original.png` | `01-mainmenu-gpt-image2_palette24.png` | 越界 0% / 柔边 0% / 纯白 0.03%，仅剩尺寸 |

> 模型选型：GPT-Image-2.0（硬边像素、中文不崩、无水印）；豆包出的是平滑矢量描金，
> 不满足像素硬约束，不用于本目录。参考稿仍不入库，见上方口径提醒。

## 场景 / Boss / 特效回稿（第 27 轮起）

`docs/20` 的 A / B / C 组回稿**也放本目录**，与 UI 回稿共用同一套归档 / 吸附 / 体检流程，靠文件名前缀区分：

| 前缀 | 内容 |
|---|---|
| `00-` … `08-` | ⓪–⑧ UI 界面（第 24–25 轮，18 张） |
| `A1-` … `A4-` | 4 类塔层背景（16:9，默认 screen 模式） |
| `B-` / `C1-` / `C2-` | Boss 概念 / 技能形状板 / overlay 形状板（方图 sprite 类，`size_rule` FAIL 按 R55 豁免） |

> **第 27 轮用户决策**：A 组按已生成现状收编，**不要求重出 16:9、不要求重切四层**（「凑合用，不行了后面再换」）。

> 客观记录：A2 最亮最空、对 R22 最友好；A3 偏暗（地面浅色仅 14.9%），阴兵对比度风险最高；A4 是四张里唯一的 16:9，但 1536×864 不是 480×270 整数倍。
> **后续 B / C 组全部 1:1 方图，不再有 16:9 回稿。**
