### 4.7 第 41 轮：工作空间迁址与路径断言解耦（**先看这节**）

第 41 轮（2026-11-11）本工程所在的工作空间根迁到了另一台机器上的**固定名 `ai-game/` 根**（工作空间根的上级目录随机器而定，**文档与自检都不再写死盘符**）。直接后果与处置：

- **旧断言失效**：`tools/final_selfcheck.py` 的 `workspace_moved_r17` 曾写死「工作空间根必须是 `~/Documents/ai-game`」，迁址后它成了 38 项自检里**唯一 FAIL**。该写法既**违反项目第 ④ 条约定**（禁写机器绝对路径），也把「工程在稳定工作空间根下」这一**结构事实**绑死成某台机器的**具体位置**，换机器必然失效。现已改为**结构性断言**：工作空间根是固定名 `ai-game/`，且其上级不是带时间戳的会话目录（R17 的原始关切）。
- **新增第 39 项** `workspace_path_r41`：**动态取本机实际路径**（反斜杠 + 正斜杠两种写法）扫描全部文档，机器绝对路径命中 0 —— **换机器不用改代码**。
- **R63（同一类缺陷）**：卡牌插画映射表里 72 张卡的 `status` 曾被**写死**成「待外发 · 未回稿」，与同一文件 `stats` 里 `sheetsReceived=6 / artReceived=72` 自相矛盾；自检还**写死断言**「所有卡都未回稿」，等于把错误状态锁死。现已改为**按磁盘实况**判定：转录产物已落盘 → 「已转录 · 候选资产；待目检与合规确认；不得直接入库」，未落盘 → 「待外发 · 未回稿 …」；自检改为断言「状态与磁盘一致」，且「候选资产 / 不得直接入库」红线不变。
- **迁址本身零产出改动**：`project.godot` 主场景、冻结 10 张卡面、`docs/12` 冻结口径、数值 / 概率 / 权重 / 抽卡规则均**一个字节未动**；本轮只改了自检断言、生成器的状态口径与文档表述。全量自检 **39/39 PASS**。
- **完整改前/改后对照见** **`docs/29-工作空间迁址与路径断言解耦.md`**。
