## 0. 一句话

第 41 轮的可玩闭环里，卡牌效果只落地了「触碰五上界变量」的数值部分
（`CardDeck.apply_params()` → `BattleFormula.damage_formula()`），其余机制键
（`split` / `shield_max` / `on_kill` / `revive_hp` …）在 `TowerRun._on_card_picked()` 里
**只把 id 记进 `picks`，战斗层不消费**——选一张「飞剑分裂」和选一张无关卡，打起来一模一样。
用户最初的设计诉求正是「每张卡独立、突出选卡的重要性」，这个缺口直接违背它。

网页验证层第 21 轮已有 `tools/card_effects.js`（44/44 回归）把冻结卡库的 params 编译成
20 字段 EffectSet。本轮把它**逐字段移植成 Godot 侧 `scripts/CardEffects.gd`**，
并接进 `StageView` 的战斗消费点。76 样本跨端逐字段比对 100% 一致。

## 1. 改前 → 改后对照（约定②：不原位覆盖）

| 项 | 改前（第 41 轮） | 改后（第 42 轮） |
|---|---|---|
| 效果编译 | 无，`picks` 只登记 id | 新增 `scripts/CardEffects.gd`，从冻结卡库编译 20 字段 mods |
| `_on_card_picked()` | `deck.pick()` + `picks.append()` | 追加 `stage.apply_mods(effects.compile(picks))` |
| 多段命中 | 技能自带 `hits`，全满伤 | `segmentRatios` 决定分段比例，总伤不变（默认 `[1.0]` = 原行为） |
| 破防 / 承伤 | 只用五上界 `defense_rate` | 追加 `pierceDefense`（攻击侧）、`damageTakenScale` / `flatReduce`（玩家侧） |
| 护盾 / 复活 / 回灵 | 无 | 每层护盾、本局首次复活、击杀/命中/受击回灵 |
| HP/灵力上限 | 固定 `RunConfig` 常量 | `hpMaxFlat/Ratio`、`spiritMaxFlat/Ratio` 生效，`snapshot()` 暴露 effective 上限 |
| 移速 / 暴击率 / 免费施法 / 显示敌人 HP | 无 | 各自接入，默认不改变行为 |

**冻结基线逐字节未动**：`data/buff-card-library.json`、`BattleFormula.gd` 五上界、
`docs/01/11/12` 冻结口径、`assets/ui/cards/` 10 张卡面、`project.godot` 主场景（仍 TowerRun）。
07 候选卡框（R61）仍不采用，游戏本体源码零 `res://previews/card_frames_codex` 引用。

## 2. 跨端口径（R47 / R56 的口径，不是逐帧一致）

- `tools/card_effects.js`（网页，源）→ `docs/card-effects-golden.json`（76 样本黄金快照，Node 生成）
  → `scripts/CardEffects.gd`（Godot，移植）→ `tools/verify_card_effects.gd`（headless 逐字段比对）。
- **76 样本 = 全部 72 张单卡 + 默认 + 3 个堆叠组合**；20 字段逐一比对（浮点容差 1e-6），
  10/10 PASS。逐卡特例（丹香不套全局灵耗、破云分段、接气受击回灵、舍利复活、天人显示、
  五行逆克因词缀系统未建而不映射）全部对齐。
- 诚实边界：`_truthy()` 对齐 JS 的 truthy 语义（非空字符串为真），因为 `affix` 值是
  `"affix_tiebi"` 字符串——第一次移植按 `"true"` 判定导致 `card_wuxing` 不匹配，已修正。
- **这只保证 mods 编译结果一致，不代表逐帧状态机一致（R56 仍未解决）**，不得宣称
  「网页测过 = Godot 逐帧一致」。

## 3. 20 个字段与落点（全部 PROPOSAL / 安全上界，非平衡值）

| 字段 | 落点（StageView） | 默认 | 语义来源 |
|---|---|---|---|
| segmentRatios | `_cast()` 每段伤害比例 | `[1.0]` | 破云/引雷/拳风 |
| pierceDefense | `_cast()` 折减敌人 defense | 0 | 破域（无条件 5%） |
| shieldMax | `start_stage()`/`apply_mods()` 每层护盾 | 0 | 卷甲 |
| cdScale | `_cast()` 技能 CD | 1 | 轻灵/无根/舍身 |
| spiritCostScale | `_cast()` 灵力消耗 | 1 | 升息（丹香限定不套） |
| freeCastOnFull | `_cast()` 满灵免费（限 3 次） | false | 灵潮 |
| spiritOnKill | `_cast()` 击杀回灵 | 0 | 聚灵 |
| spiritOnHit | `_cast()` 命中回灵 | 0 | 逆转回灵（年转） |
| spiritOnHurt | `_tick_enemies()` 受击回灵 | 0 | 接气 |
| hpMaxFlat/Ratio | `reset_player()`/`apply_mods()` 上限 | 0 | 凝丹/寿元/舍身 |
| spiritMaxFlat/Ratio | 同上 | 0 | 灵脉/无根 |
| moveSpeedBonus | `_tick_player()` 移速 | 0 | 步摇 |
| hurtInvuln | `_tick_enemies()` 受击无敌窗口 | 0 | 避水 |
| critRateBonus | `_cast()` 暴击率 | 0 | 淬精 |
| damageTakenScale | `_tick_enemies()` 承伤系数 | 1 | 铁皮/混元/守拙 |
| flatReduce | `_tick_enemies()` 固定减伤 | 0 | 铁骨 |
| reviveHp | `_tick_enemies()` 本局首次复活 | 0 | 舍利/转生 |
| reveal | `snapshot()` 显示敌人 HP 标记 | false | 天人感应 |

**语义未定 / 归局外系统的键仍不模拟**（`heal` 比例、`convert`、`regen`、`dot_stack`、
`recompute_B`、`legacy_*`、`reward_clamp` 等，NONE_REASON 清单见 `card_effects.js`）——
不猜数值、不伪造效果。治疗技能只按 `RunConfig.SKILLS` 固定治疗量，不按卡牌比例缩放。
