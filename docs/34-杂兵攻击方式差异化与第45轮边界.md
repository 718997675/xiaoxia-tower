# 第 45 轮 · 杂兵攻击方式差异化（Godot 表现层）

## 一句话

第 41 轮可玩本体里 4 种杂兵（山魈 / 纸傀 / 阴兵 / 剑魂）只有 `defense` / `speed` 不同，
攻击方式完全一样（走近平砍）——这正是「每张卡、每个设计点都要有辨识度」诉求里缺失的一环。
本轮给每种杂兵一个独立攻击风格，让战斗有可读的差异；全部是 PROPOSAL 表现层增强，
不改任何冻结数值、不新增出图。

## 做了什么

### 四种攻击风格（RunConfig.MOB_ATTACK_STYLE，PROPOSAL）

| 杂兵 | 风格 | 攻击方式 | 出手间隔 | 伤害比例 | 复用特效帧 |
|---|---|---|---|---|---|
| 山魈 `mob_shanxiao` | 重击 | 近战，慢而重 | 2.8 s | 1.45× | `vfx_fist_force` |
| 纸傀 `mob_zhi_kui` | 符弹 | **远程投射物，可闪避** | 2.2 s | 0.85× | `vfx_paper_puppet` |
| 阴兵 `mob_yin_bing` | 常规 | 近战（**基准档，行为不变**） | 1.9 s | 1.0× | `vfx_hit` |
| 剑魂 `mob_jian_hun` | 疾刺 | 近战，快而轻 | 0.9 s | 0.62× | `vfx_sword_qi` |

- 伤害比例作用于该层通用 `incoming`（与第 41 轮同一基准：`ENEMY_ATTACK_BASE + PER_STAGE×层号 + dps×0.12`），
  不是冻结数值、不是平衡结论（R51）。
- 全部特效帧来自既有 `assets/vfx/frames/`（gpt-image2 回稿转录，docs/24），**未新增出图**。
- 远程弹速 150 px/s、存活 3 s，也是 PROPOSAL 占位。

### 实现落点（scripts/StageView.gd）

1. 敌人生成时附带 `style` 字典（Boss / 未配置拿到空字典 → 走原有行为）。
2. `_tick_enemies()` 按 `style.ranged` 分支：
   - 远程兵保持距离（站到 `ENEMY_ATTACK_RANGE×2.4` 边缘）发弹，不贴脸；
   - 近战兵沿用第 41 轮追击与命中口径，仅按 `dmg` 比例缩放伤害；
   - **阴兵「常规」档与 Boss 逐字段不变**（`dmg=1.0`、空 style 走原路径）。
3. `_fire_mob_ranged()`：远程兵发单发直线弹，伤害 = `incoming × dmg`，命中走第 44 轮
   `_hurt_player()` 统一路径（减伤 / 护盾 / 受击无敌 / 复活 / 死亡逐字段一致），**可闪避**。
4. `_spawn_projectile()` 泛化：新增 `vfx_id / speed / life` 三个可选参数，默认值 = 第 44 轮
   Boss 口径，因此 **Boss 的四参数调用逐字段不变**；远程兵传风格参数复用同一套飞行 / 命中系统。

### headless 验证（tools/verify_tower_run.gd）

可玩闭环从 37/37 扩到 **45/45**（原 37 项不回退 + 新增 8 项）：

- `mob_style_table_shape`：4 风格齐备、vfx 帧存在
- `mob_styles_distinct`：重击 CD / 伤害 > 疾刺、纸傀远程、阴兵基准 dmg=1.0
- `mob_styles_in_stage`：stage 6 敌人携带正确风格，Boss 层无注入
- `mob_ranged_fires`：纸傀强制攻击发 1 弹
- `mob_ranged_hit_damages`：远程弹命中扣血（实测 300→273.1）
- `mob_ranged_dodge_ignores`：无敌时穿过不扣血（273.1→273.1）
- `mob_melee_dmg_scaled`：重击扣 45.9 > 疾刺扣 19.6
- `mob_boss_style_unchanged`：Boss 层风格为空

## 诚实边界

- **R56 逐 tick 仍未跨端对齐**：网页验证层没有杂兵攻击风格系统，这是 Godot 独有表现层增强，
  不宣称「网页测过 = Godot 一致」。
- **R67（本轮新增）**：攻击风格参数（CD / 伤害比例 / 弹速）是表现层拍脑袋值，未经手感实测；
  纸傀远程弹在 stage 7（4 怪同场）叠加时可能偏密，需 F5 目检后调。
- GUI 实机 F5 仍未目检：投射物朝向 / 扇形观感 / 中文飘字 / 难度手感需玩家确认。
- 阶段 / 弹幕 / 杂兵风格均非冻结规格、非平衡结论（R51），只保证 Godot 侧自洽可跑。

