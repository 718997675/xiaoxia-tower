### 跨轮不能丢的四条结论

1. **30 h 是「一期+二期」合计目标**，一期诚实口径 6–17.6 h。补缺口三杠杆都**不加内容**：解锁链 27→45–60（每境 ≥2 项新玩法）、靠 M6 埋点实测提高 `η`、二期无尽天梯 + 个人最高层（但 `M(n)` 机制质变做不出来就不许开）。
2. **别先做无尽塔**：没有 `M(n)` 只是把「不够耐玩」推迟到第 25 层再暴露一次。P0-1 构筑空间收益最大、成本最低。
3. **P0-1 / P0-2 / P0-3 是耐玩性地基，不能砍**。砍需求顺序：P2 图鉴/成就 → P1-4 道途目标先做 4 个 → P1-6 重掷后置。
4. **AI 素材不能直接入库**：帧间一致性、脚底锚点、镜像光向、判定框对齐、调色板越界、版权与风格合规都需人工过一遍。

## 7. 素材生产链路（可复现）

```
① 出图：文生图，prompt 必须显式写死
   「方形像素块 / 硬边 / 无抗锯齿 / 无平滑渐变 / 少量色阶 / 纯白底 /
     限定 24 色板 / no text no numbers no grid lines」
   技巧：一张图内 2×2 多格动作条 → 帧间一致性远好于分别生成 4 张
② 目检：看图，不像就改 prompt 重生成，最多 2–3 轮
③ 规整：切片 → floodfill 去白底 → 缩到 64×64 → 透明硬边 → 调色板吸附
④ 合成：一个 Sprite 内 add_frame() 出 spritesheet + 动画 GIF + 引擎 JSON
⑤ 质检：数值质检脚本，>=80 SHIP / 60-79 FIX / <60 REDRAW
⑥ 交付：1x PNG / 放大预览 / GIF + 精灵图 + JSON / 报告
⑦ 预览：`python3 tools/build_preview.py` → 自包含 `vfx-preview.html`（可播放 / 逐帧 / 施法合成 / 判定框叠加 / 自动发现素材组）
   ↳ 规整脚本已支持 `--kind char/mob/boss/vfx`、`--size`、`--cells`、`--hollow`、`--append`；修复见 `05` §7/§8。批量重跑**写显式帧名**，勿用 zsh 变量传空格串。
   ↳ 同角色跨批次补帧用**图生图**（`image1` 传既有源图 + `input_fidelity=high`）保服饰一致；每批 `--append` 合并到同一引擎 JSON。
   ↳ 空心特效（环 / 罩）必须加 `--hollow`，否则内部白底不与边缘连通，会留下实心白饼。
⑧ 精修与合规确认 → 按 manifest 命名入库 → Godot 导入核对
⑨ **图标 / 挂件（第二条链路，0 积分）**：`python3 tools/build_icons.py` 按 `07` 三层形状语法程序化绘制 → `docs/icon-catalog.json` → 6× 并排拼图目检 → `qc_sprites.py` loose 扫描。有机形态（角色/怪物/Boss）**仍走 ①–⑧**，不要用几何画。

   ↳ `qc_sprites.py` 每次新增批次后跑**全量**复核，不只查新帧（R19）；阈值口径见 R21。
⑩ **决策追溯（第 15 轮起为阶段二口径）**：`python3 tools/check_traceability.py` 同时核对 `docs/design-freeze-draft.json`（历史快照，仍须 `draft`）与 **`docs/design-freeze.json`（当前权威，须 `frozen`）**，扫描 `assets/ + tools/ + scripts/ + scenes/ + project.godot`，**只认 `@trace` 后的编号**。当前 **4/22 = 18%**，与技能包 `check_godot_project.py --freeze` 口径一致；低覆盖率是最小验证工程真实进度，**不许手工塞标记凑数**。
⑪ **决策收敛（第 11 轮，0 积分）**：`python3 tools/build_decision_card.py` 从 `decision-card.json` 重建决策卡 → 用户在页面逐项勾选并复制回执 → `python3 tools/apply_decisions.py --receipt <文件>` 先 dry-run 校验 → 确认无误加 `--apply` 写 receipt/plan → **助手再按 plan 逐条落地**。
   ↳ 收到回执前**不生成 18 件图标**（Q25/Q26 提案未确认，先画必返工）；Q1 必须由用户填本机实际 Godot 版本，助手不代填。
   ↳ `apply_decisions.py` 的硬断言不许绕过：`frozen=false`、写入路径白名单、不改 `01`–`08` 正文、不建工程。
```
