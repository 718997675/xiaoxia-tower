# 第 47 轮 · 玩家技能施法演出差异化（Godot 表现层）

## 背景与动机

第 41–46 轮把可玩本体、机制卡效果、Boss 三阶段、Boss 远程弹幕、杂兵差异化、打击感反馈都补齐了。但玩家自己的四个技能此前**施法演出完全相同**：`_cast()` 里一律在玩家身前同一位置播一个 `s["vfx"]`，四个技能只有帧不同、没有"打法形态"区别。这与项目反复强调的「每个设计点都要突出、不能有重复感」相悖。本轮给四个技能各一种弹道形态，纯视觉、零战斗数值影响。

## 做了什么（全部 PROPOSAL，非冻结、非平衡结论 R51）

### 形态表（`RunConfig.SKILL_CAST_STYLE`）

| 技能 | id | 形态 style | 帧（复用现有） | 节点数 | 运动 |
|---|---|---|---|---|---|
| 剑气斩 | sword_qi | `dash` 前冲 | vfx_sword_qi | 1 | 沿面向水平飞出 240px/s，缩放 1.0→0.85 |
| 引雷符 | thunder_talisman | `strike` 天降 | vfx_thunder_talisman | 1 | 从目标上方 320px/s 垂直砸落，缩放 0.8→1.25 |
| 三昧丹火 | dan_fire | `spray` 扇形喷射 | vfx_dan_fire | 3 | 3 节点 ±0.14rad 扇形散开 160px/s，缩放 1.0→0.7 |
| 回春诀 | rejuvenation | `aura` 自身光环 | vfx_rejuvenation | 1 | 自脚下 22px/s 上浮，缩放 0.7→1.35 |

- 全部复用 `assets/vfx/frames/` 现有真帧（即 `SKILLS[].vfx` 已有帧），**未新增任何出图**。
- 数值（速度 / 存活 / 张角 / 缩放）全集中在 `RunConfig.SKILL_CAST_STYLE`，不新开数值池（R51）。

### StageView 实现

- 新增 `CastFx` 演出层（`cast_fx_root`），与命中判定、投射物、玩家逻辑坐标完全解耦。
- `_spawn_cast_fx(skill_idx)`：按形态生成 `AnimatedSprite2D` 节点，四种 `match style` 分支各自决定起点 / 速度 / 旋转 / 缩放曲线。
- `_tick_cast_fx(delta)`：在 `_process()` 里用真实 delta 推进位置与缩放，超时 `queue_free`；暂停时也让演出自然播完，**不进入战斗 tick**。
- 切层 / `stop()` 时 `_clear_cast_fx()` 清空，不跨层残留。
- `snapshot()` 暴露 `cast_fx_count` / `cast_fx_total` / `last_cast_style` 供 HUD 与 headless 校验。

### 零数值影响（关键纪律）

- `_cast()` 中演出调用 `spawn_cast_fx` **之后**，命中判定 / 伤害公式 / 灵力扣除 / CD / 治疗 / 连击里程碑全部按原样执行，演出不参与任何结算。
- 演出节点只在独立 `CastFx` 层活动，不写玩家 / 敌人 / 投射物坐标，不影响 `_hurt_player()`、`_check_boss_phase()` 等路径。
- 第 41–46 轮的 51 项闭环断言逐条不回退。
