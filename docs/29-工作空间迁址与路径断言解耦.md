### 1.2 `git pull` 连续失败的真因：残留的 `index.lock`

拉取连续两次被 SIGTERM 中断。排查结论：**不是网络、不是权限、不是认证**——仓库里残留了一个 `.git/index.lock`（早前被强杀的 git 进程留下的），**所有 git 写操作都被它挡住**（`stash` / `merge` 均报 `Unable to create ... index.lock: File exists`）。确认无 git 进程在跑后清除该陈旧锁，fetch / merge 一次通过。

> 教训：git 报「看起来像网络/权限问题」时，先看 `.git/*.lock` 残留，再排查网络。

## 2. R62：路径断言把机器绝对路径写死

### 2.1 现象

全量自检 38 项里**唯一 FAIL**：

```
FAIL | workspace_moved_r17 | AssertionError: 工作空间根目录应为 ~/Documents/ai-game（当前：<本机工作空间根>）
```

### 2.2 根因

`tools/final_selfcheck.py → c_workspace_moved()` 里这一条断言：

```python
need(ROOT.parent.parent.name == "Documents",
     f"工作空间根目录应为 ~/Documents/ai-game（当前：{ROOT.parent}）")
```

它有两个问题：

| # | 问题 | 说明 |
|---|---|---|
| ① | **违反项目第 ④ 条约定** | 约定原文：「文档内禁止写机器绝对路径，一律用项目内相对路径」。自检脚本虽不属于「文档」，但把某台机器的目录结构写进**可复算断言**，等于把一次性环境事实当成长期不变量 |
| ② | **把结构事实绑死成机器位置** | R17 的真实关切是「工程在**稳定**的工作空间根下，不再落在带时间戳的会话目录里」。断言只钉死了 `~/Documents` 这一个具体父目录名，于是工作空间根一迁址就必然 FAIL —— 而迁址本身**没有违反**任何约定 |

### 2.3 改前 / 改后对照

| 项 | 改前 | 改后 |
|---|---|---|
| 位置断言 | `ROOT.parent.parent.name == "Documents"`（硬编码某台机器的父目录名） | **结构性**：工作空间根名必须是 `ai-game`，且其上级**不得**是带时间戳的会话目录（正则 `^\d{4}-\d{2}-\d{2}(-\d{2}-\d{2}-\d{2})?$`） |
| 文档必含串 | 接手指南与交接文档必须含 `~/Documents/ai-game/`（机器路径） | 泛化为 `ai-game/`（相对路径表述） |
| 失败信息 | 直接打印 `ROOT` / `ROOT.parent` 绝对路径 | 只打印**目录名**，不泄露路径 |
| 换机器 | 必然 FAIL，需改代码 | **无需改代码** |
| R17 原始关切（不再在会话目录） | 由 `Documents` 这个硬编码名顺带保证 | 由**显式的会话目录正则**直接保证（更准、更可读） |
| R44 口径（接手指南唯一在工程根） | 保留 | **保留，未动** |

## 4. R63：卡级 `status` 写死「未回稿」，与 `stats` 自相矛盾

### 4.1 现象

`docs/card-art-plan.json` 里，同一个文件的两处口径打架：

| 位置 | 值 | 来源 |
|---|---|---|
| `stats.sheetsReceived` / `stats.artReceived` | **6 / 72**（全部到齐） | 按磁盘**动态**统计 |
| `cards[*].status` | **「待外发 · 未回稿」**（72 张全部） | **写死的常量** |

更糟的是自检第 34 项里还有一条断言：

```python
need(all(c["status"] == "待外发 · 未回稿 · 候选资产；不得直接入库" for c in cards),
     "有卡被标成已入库")
```

—— 它把**错误的现状**当成不变量锁死了。接手者读 `docs/00` §9 会看到「6 张回稿尚未生成（`sheetsReceived=0/6`）」，据此以为下一步是「等回稿」，而回稿其实早已到齐并转录落盘。

### 4.2 改前 / 改后对照

| 项 | 改前 | 改后 |
|---|---|---|
| 卡级 `status` | 写死「待外发 · 未回稿 · 候选资产；不得直接入库」 | **按磁盘实况判定**：转录产物 `assets/ui/card_art/<card_id>.png` 已落盘 → 「**已转录 · 候选资产；待目检与合规确认；不得直接入库**」；未落盘 → 「待外发 · 未回稿 · 候选资产；不得直接入库」 |
| 映射表顶层 `status` | 只写「第 34/35 轮出图方案」 | 补上「第 39 轮 6 组回稿已到齐并转录为候选插画」 |
| 自检断言 | 断言 72 张卡的 `status` **等于那个写死串** | 断言**状态与磁盘一致**（已落盘不得标「未回稿」；未落盘不得标「已转录」）**且**「候选资产 / 不得直接入库」红线一条不许丢 |
| 口径红线 | 隐含在常量里 | **显式断言**，任何「已入库」式措辞都会被拦下 |
| 换机器 / 再来 6 组回稿 | 仍需改代码 | **自动适配**（判据是磁盘，不是常量） |
