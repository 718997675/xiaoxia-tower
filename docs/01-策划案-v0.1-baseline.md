## 1. 一句话定位

一个想「渡劫」的散修，在九重天梯里逐层横版血战、每层三选一拼出当局限定流派；败了也不白打——带走一条传承灵韵与修为，下一局从更高境界重来。

## 2. 品类与对标

| 项 | 内容 |
|---|---|
| 品类标签 | 2D 横版动作 / 爬塔 Roguelite / Build 构筑 |
| 机制层借鉴 | 层进式爬塔 + 层间三选一构筑（机制层）、局外永久遗产（机制层）、横版即时战斗（机制层） |
| **差异点** | ①「修真境界」作为**局外永久进度轴**，「塔层」作为**局内进度轴**，两轴严格分离；②继承不搬整件装备，只固化**一条词条/灵韵**，抗数值膨胀；③技能特效与伤害判定彻底解耦，特效不参与节奏 |
| 不取 | 不借鉴任何作品的美术、角色、专有名词与境界设定 |

## 3. 目标用户与场景

- 用户：25–40 岁、熟悉 Roguelite 与仙侠题材、能接受中等操作强度的单机玩家。
- 场景：桌面端连续 20–40 分钟，一次打 2–3 局；单局 8–12 分钟。
- 变现：按 A4 假设「纯兴趣 / 买断」，无内购、无广告、无联网（Q9 若变更，将改写本章与经济三件套）。

## 5. 核心循环（三层，含耗时与流失点）

**一句话**：入塔 → 横版即时战斗清层 → 三选一（装备 / 技能 / 词条）→ 推进层数 → 败或通关结算 → 固化 1 条传承灵韵 + 累积修为突破境界 → 再入塔。

| 层级 | 环节与耗时 | 流失点 | 对策 |
|---|---|---|---|
| 微循环（0.2–3 s） | 移动/闪避 0.1 s → 选技能 0.1 s → 释放 → **同帧判定 + 特效请求** → 命中反馈 ≤0.2 s | 反馈延迟 >0.2 s 显得「发粘」 | 判定与特效解耦；命中闪白 + 停顿帧 + 飘字；特效异步播放不阻塞结算 |
| 单局循环（8–12 min） | 入塔 5 s → 9 层战斗共 436 s → 层间三选一 8×10 s = 80 s → 结算 8 s ≈ **8.8 min** | 层间三选一「选了没感觉」 | 三选一强制含 ≥1 个能改变本局 build 的选项；选项显示预期 DPS 变化 |
| 长线循环（跨局 30–60 min） | 结算 → 传承灵韵 +1 → 修为累积 → 境界突破（解锁技能/槽位）→ 再入塔 | 连败零收益导致弃游 | 失败也按到达层数给修为保底（见经济三件套）；**每局结束必须产生 ≥1 项长期收益** |

决策密度：战斗中约每 4–6 秒一次有意义选择（走位 / 技能顺序 / 是否交大招），层间每 45 秒一次构筑选择 → 无连续 30 秒空白，无每秒 >1 次的过载。

## 6. 核心机制清单（规则 + 玩家感知）

| 编号 | 机制 | 作用 | 触发 / 输入 / 规则 / 输出 / 边界 | 玩家感知 |
|---|---|---|---|---|
| M1 | 技能释放与冷却 | 把操作转成结果 | 触发：按下 `skill_1..4`；输入：4 技能槽 + `dodge`；规则：状态表见下，判定矩形 96×128 px、中心在身前 64 px×facing、层 `hitbox→hurtbox`、冷却单位秒且受时间缩放影响、同屏特效上限 24（超出淘汰最旧）、平局按 `skill_priority` 降序 + 节点 id 小者优先；输出：同帧发 `vfx_requested` 与 `damage_applied`；边界：见边界表 | 按下即出光、即出数，不等动画 |
| M2 | 修真境界 | 局外永久成长轴 | 触发：结算后修为达阈值；输入：自动；规则：`realm_ratio` 分段线性 1.00→4.00（9 境），只提升**上限与解锁**，不直接加局内伤害基数；输出：`meta_realm_changed` + 光柱；边界：修为溢出转灵石、境界封顶第 9 境 | 每几局「破境」，开新技能 |
| M3 | 装备与传承灵韵 | 局内构筑 + 局外继承 | 触发：层间三选一 / 结算；输入：3 选 1 / 1 条固化；规则：局内装备**整件随局清空**；结算时从本局装备抽 **1 条词条**固化为「传承灵韵」，上限 6 条，超出按「最旧优先」替换；灵韵在塔内只按 50% 计入 `extra_pool`；输出：下一局初始属性变化 + 印章动效；边界：空局（0 层）不产出灵韵、重复词条不叠加 | 败了也带走一条，越打越厚 |
| M4 | 爬塔层数与难度波形 | 单局推进与节奏 | 触发：清层 / 层间选择；输入：3 选 1；规则：9 层，第 3/6/8 层为喘息层，Boss 在第 9 层；难度系数由公式生成（第 8 章）；输出：`stage_cleared`；边界：断线/重开回到层首、不保留层内随机 | 有起有伏，第 9 层是验收 |
| M5 | 横版 PK 与朝向 | 战斗表现基础 | 触发：移动输入；输入：`move` + `dodge`；规则：素材只出**朝右一套**，角色 `Sprite2D` 与特效节点按 `facing` 做 `scale.x = ±1` 镜像，**不镜像整个场景**（否则文字/UI 反向）；输出：左右朝向 + 判定框翻转；边界：`facing` 只能为 ±1，0 视为 +1 | 左右打起来一致，不穿帮 |

## 8. 数值与成长框架（全部「待实测」）

### 8.1 统一伤害公式（乘性结构，便于归因）

```
final = clamp( round( (base × realm_ratio + extra_pool) × combo_mult × crit_mult × (1 − defense_rate) ), 1, 9999 )
```

| 变量 | 含义 | 取值范围 | 单位 |
|---|---|---|---|
| `base` | 技能基础伤害（局内可成长） | 20–180 | 点 |
| `realm_ratio` | 境界倍率（局外） | 1.00–4.00 | 倍 |
| `extra_pool` | 装备 + 传承灵韵附加池（灵韵按 50% 计入） | 0–600 | 点 |
| `combo_mult` | 连击 / 流派倍率 | 1.0–2.5 | 倍 |
| `crit_mult` | 暴击倍率（暴击时 1.8，否则 1.0） | 1.0 / 1.8 | 倍 |
| `defense_rate` | 敌人减伤率 | 0–0.75 | 比例 |

**极值验算**（可用 `docs/数值框架.csv` 复算，或运行下方命令）：

| 场景 | 代入 | 结果 | 判定 |
|---|---|---|---|
| 全最小值 | (20×1.00+0)×1.0×1.0×(1−0.75) | **5** | ≥1，无需钳制 |
| 期望中期 | (60×1.60+120)×1.0×1.0×(1−0.30) | **151** | 作为第 5 层平衡锚点，待实测 |
| 全最大值 | (180×4.00+600)×2.5×1.8×1.0 | **5940** | ⚠️ **超出承载**：第 9 层敌人总血量仅 4400，满配置可一击清层，终局战斗时长红线（≥25 s）被击穿 |
| 边界扣除 | 负 `realm_ratio` / `extra_pool` | 负值 | 钳制到最小值 1，并显式报错 |

**红线对策（二选一，列入 Q6）**：A. 允许终局碾压 → Boss 血量按境界动态缩放；B. 保持张力 → 塔内对 `realm_ratio` 与 `extra_pool` 施加压制系数（如局内封顶 1.75 / 300）。两案均**未在编辑器实测，标「待实测」**。

离线复算命令（零依赖，可直接粘贴运行）：
```bash
python3 - <<'PY'
def dmg(base, realm, pool, combo, crit, defense):
    raw = (base * realm + pool) * combo * (1.8 if crit else 1.0) * (1 - min(max(defense, 0), 0.75))
    return max(1, min(9999, round(raw)))
print("全最小", dmg(20, 1.0, 0, 1.0, False, 0.75))   # 5
print("中期",   dmg(60, 1.6, 120, 1.0, False, 0.30)) # 151
print("全最大", dmg(180, 4.0, 600, 2.5, True, 0.0))  # 5940
PY
```

### 8.3 关卡难度波形（可一键复算）

```
T(n)        = HP_total(n) / P_dps(n) × 1.3      # 1.3 = 走位损耗系数
D(n)        = T(n) / T(1)                       # 难度系数，第 1 层归一为 1.00
HP_total(n) = 该层敌人血量总和（点）
P_dps(n)    = 玩家进入第 n 层时的期望有效 DPS（点/秒，含局内成长）
```

| 层 | `HP_total` | `P_dps` | `T(n)` 秒 | `D(n)` | 类型 |
|---|---|---|---|---|---|
| 1 | 300 | 10 | 39 | 1.00 | 教学 |
| 2 | 480 | 14 | 45 | 1.15 | 常规 |
| 3 | 440 | 16 | 36 | 0.92 | 喘息 |
| 4 | 700 | 20 | 46 | 1.18 | 常规 |
| 5 | 920 | 24 | 50 | 1.28 | 挑战 |
| 6 | 780 | 28 | 36 | 0.92 | 喘息 |
| 7 | 1150 | 34 | 44 | 1.13 | 常规 |
| 8 | 1160 | 42 | 36 | 0.92 | 喘息 |
| 9 | 4400 | 55 | 104 | 2.67 | 塔主 Boss |
| **合计** | — | — | **436** | — | + 层间 80 s ≈ **8.8 min** |

校验：喘息层 3/6/8；最长连续上升 2 层（4→5、1→2）；无连续 3 关以上单调上升；`D(n)` 全部由公式生成，与 `docs/数值框架.csv` 同源，不存在两套口径。

### 8.4 经济三件套

| 项 | 口径 |
|---|---|
| 产出 | 每层清层 `8 + 2×层数` 灵石 → Σ(n=1..9) = 162；Boss 额外 30 → **单局 192 灵石**；失败额外按到达层数给修为保底 `5×层数` |
| 消耗 | 传承固化 100 灵石/条（每局 1 次）；层间铸器 25 灵石/次（每局约 2 次）；境界突破 `100×境界序号`（跨局，非每局） |
| 存量 | 灵石上限 9999，溢出按 1:1 转修为；修为无上限但境界封顶第 9 境 |
| 比值检验 | 单局产出 192 ÷ 单局消耗 150 = **1.28**，落在目标区间 1.1–1.4 |

### 8.5 掉率与期望（每局 9 次清层机会，单局 8.8 min）

| 物品 | 稀有度 | 单次掉率 | 保底 | 期望次数 | 玩家时间成本 |
|---|---|---|---|---|---|
| 凡品装备 | 常见 | 45% | 无 | 2.22 | 0.25 局 ≈ 2.2 min |
| 灵品装备 | 稀有 | 8% | 12 次必出 | ≈8.3 | 0.92 局 ≈ 8 min |
