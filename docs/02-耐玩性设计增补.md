# 02 · 耐玩性设计增补（v0.2 提案 · 待确认）

> 触发：用户担心「玩法不够耐玩」，目标是 **内容量不大但够肝**。
> 定位：对 `01-策划案.md`（v0.1 基线）的**修订提案**，不是新策划案。01 保留不改，便于改前 / 改后对照。
> 口径：只借鉴对标作品的**机制层**，不取美术、角色、专有名词；具体级数与数值以官方当前版本为准（本轮未核验版本细节）。
> 所有估算量一律标「待实测」，不得当作已验证的平衡结论。

## 1. 先把「够肝」拆清楚（这是本轮最重要的判断）

「内容量不大」和「够肝」不矛盾，但**不能靠堆时长实现**。同一个词底下是两种完全不同的设计：

| | 疲劳型肝 Grind | 耐玩型肝 Replay（**建议目标**） |
|---|---|---|
| 靠什么拉时长 | 重复劳动 + 低掉率 + 时间门槛 | 每局的**决策空间变化** |
| 玩家感受 | 「还得刷」「终于出了」 | 「这局换个打法试试」 |
| 数值表现 | 单局长、局数少、流失于 bored | 单局短、局数多、流失于「内容见底」 |
| 代价 | 差评、疲劳、对小团队是负担 | 需要设计**组合与变化**，不是加资源 |
| 典型反例 | 纯刷装备词条的低概率池 | — |

**结论**：你要的应该是「玩家愿意主动再开一局」，而不是「玩家被逼着多待一会儿」。所以本轮所有调整围绕一个指标：

```
内容复用率 R = 有效局数 N ÷ 内容单元数 U
```

目标是让**同一套 9 层塔、同一批敌人**被消费几十次仍不重复。U 不变甚至变小，N 变大 —— 这才是「内容量不大但够肝」。

### 现方案为什么撑不住（基于 01 的真实诊断）

| # | 结构性问题 | 证据（来自 01） |
|---|---|---|
| D1 | **每局技能组合只有 1 种** | 第 6 章 M2：技能按境界解锁后固定携带，`C(4,4)=1`。这是最致命的一条——每局开局玩法完全一样 |
| D2 | 关卡完全可预测 | 8.3 的 `D(n)` 是**常量表**，第 3 次通关后所有层都可背下来，记忆取代适应 |
| D3 | 境界是纯数值链 | 8.2 `realm_ratio` 1.00→4.00，变强只让游戏变简单，不产生新决策；还直接造成 8.1 的「5940 一击清层」红线 |
| D4 | 目标单一 | 每局都是「打到第 9 层」，没有第二维度目标 |
| D5 | 词条是纯数值加成 | M3 的装备 / 灵韵只进 `extra_pool`，没有**质变协同**，最优解容易收敛成同一套 |
| D6 | 随机不可驾驭 | 三选一无重掷、无「稳健 / 赌博」分层，玩家被随机支配而非驯服随机 |
| D7 | 单局 8.8 分钟偏长 | 8.3，对「再来一局」不友好 |
| D8 | 靠低掉率拉时长 | 8.5 `legend_affix_rate=1.5%` + 60 次保底，是典型的疲劳型肝 |

## 2. 对标：找一个「内容量小但耐玩」的设计模型

| 作品 | 它怎么解决耐玩 | 内容量 | 可迁移到本项目 | 不可迁移 / 风险 |
|---|---|---|---|---|
| **《Slay the Spire》（首推骨架）** | 通关后逐级自加难度的 Ascension；卡牌与遗物**解锁链**持续扩大构筑空间；每日 / 自定义模式引入变量规则集 | 关卡结构复用，靠组合而非数量 | ① 构筑空间靠**组合与质变** ② 通关才是开始 ③ 固定关卡反复消费 | 回合制的决策密度不能直接搬到横版动作；具体级数以官方当前版本为准 |
| **《Hades》（难度变量原型）** | 首次通关后解锁 Pact of Punishment，玩家**自选** Heat 负面条件，用难度换奖励；条件迫使玩家换 build | 房间模板复用 | 「玩家自选负面条件」＝本项目**天劫词缀**的直接原型；条件必须改变决策 | 高 Heat 会**收窄可用 build**、把临场应变变成「预先解题」——所以词缀要轮换、要有克制关系；叙事驱动成本高，不适合内容量小 |
| 《Dead Cells》 | Boss Cells 逐级解锁更难区域与更好掉落；蓝图狩猎形成持续钩子 | 中等偏多 | 「下一个解锁就在眼前」的节奏 | 需要较多地图内容，与「内容量不大」冲突 |
| 《Risk of Rain 2》 | 循环关卡 + 难度缩放 + Artifacts 改写规则；资源稀缺保持取舍 | 小 | 短循环 + 规则改写 | 纯时间缩放会退化成数值竞赛 |
| ⚠️《Diablo 3》大秘境（**反面教材**） | 无限层 + 词缀 + 个人最佳 | — | 「个人最高层」作为终局钩子 | **敌人只加血加伤、不加新行为**，高层变成数值检查与「刷 favorable layout」。这是本项目无尽塔必须避开的失效模式 |

**首选组合**：以《Slay the Spire》的「解锁链 + 构筑协同」为骨架，叠《Hades》的「玩家自选负面条件」做难度变量，用「个人最高层」做终局钩子。三者共同点是**复用同一套内容**，正好卡住你「内容量不大」的约束。

> 搜索到的设计批评也印证了同一件事：无尽模式失效的根因是「scaling replaces design」——缩放取代了设计，难度只长数值不长机制。核验日期 2026-11-07，属设计观点而非权威规格。

## 3. 可复算的耐玩性模型

### 公式

```
B = F × C(S, k) × Q          有效构筑空间（数学上界）
    F 流派数 / S 技能池 / k 每局携带数 / Q 质变阈值档数

A = Σ C(M, i), i=0..j       难度配置数
    M 词缀池 / j 每局最多选几条

V = η × B × O × A           单局变体上界
    O 局目标数 / η 可行且体验显著不同的折扣（取 0.10，待实测）

L = N × T_run               总有效时长
    N 有效局数（按解锁钩子供给估算）/ T_run 单局时长
```

### 代入结果

| 维度 | v0.1 现方案 | v0.2 提案 | 计算 |
|---|---|---|---|
| `B` 构筑空间 | **1** | **840** | `1×C(4,4)×1` → `4×70×3` |
| `O` 局目标数 | 1 | 8 | 道途目标池 |
| `A` 难度配置 | 1 | **299** | `C(12,0)+C(12,1)+C(12,2)+C(12,3) = 1+12+66+220` |
| `V` 变体上界 | **1** | **200,928** | `0.10×840×8×299` |
| `T_run` 单局 | 8.8 min | 6 min（速通道途）/ 8.8 min（完整塔） | 层间选择压缩 + 5 层速通 |
| 解锁钩子 | 9（纯数值） | **27**（9 境 × 3 新池项） | 解锁链 |
| 终局 | 第 9 层结束 | 无尽天梯（数值封顶 + 机制质变） | 见 4.5 |
| **`N` 估算有效局数** | **8–15 局** | **60–120 局** | 按钩子供给推算，**待实测** |
| **`L` 估算总时长** | **1.2–2.2 h** | **6–12 h**（无尽塔追逐可到 20 h+） | `N × T_run`，**待实测** |

**诚实标注**：`V` 是**数学上界**，不等于玩家能感知的差异；`N` / `L` 建立在「玩家在遇到新要素前会继续玩」这一假设上，必须用留存埋点校准。这几个数字是用来**比较方案优劣**的，不是承诺。

## 4. 七条调整（按「每单位实现成本换来的局数」排序）

### P0-1 技能从「固定携带」改成「池选 + 质变协同」｜收益最高，成本最低

| | 改前 | 改后 |
|---|---|---|
| 技能 | 4 个按境界解锁、每局全带 | 技能池 **8**，每局开局**选 4**（层间可换 1 个） |
| 流派 | 无 | **4 流派**：剑修 / 符修 / 丹修 / 体修 |
| 词条 | 纯数值进 `extra_pool` | 带流派标签；同标签 2 / 4 / 6 件触发 **3 档质变**（例：剑意 4 件 → 飞剑分裂为 3） |

- **为什么最关键**：直接修掉 D1，`B` 从 1 变 840。质变比量变更能制造「这局不一样」。
- 成本：新增 4 个技能（已有 4 个可复用）+ 12 条质变规则；**0 个新关卡、0 套新人物素材**。
- 影响：01 第 6 章 M1/M3、第 12 章信号清单、装备与 UI。

### P0-2 天劫词缀（玩家自加难度）｜复用现有参数，0 新关卡

首次通关第 9 层后解锁。词缀池 **12 条**，每局自选 **0–3 条**，每条换奖励倍率与道行。

| 词缀示例 | 改变的决策 | 类型 |
|---|---|---|
| 心魔 | 每 30 s 失去 5% 最大灵力 → 逼迫速攻 / 带回灵 | 资源 |
| 雷劫 | 层内周期落雷 → 走位路线规划 | 空间 |
| 封印 | 禁用 1 个技能槽 → 重排 build | 构筑 |
| 疾风 | 敌人移速 +25% → 优先控制 / 远程 | 节奏 |
| 铁壁 | 敌人减伤 +15% → 需破防流 | 克制 |
| 镜反 | 反弹部分伤害 → 不能无脑站桩输出 | 输出方式 |

**硬约束**：纯数值词缀（只加血/加攻）占比 **不得超过 1/3**。理由见第 2 节 Diablo 3 的反面案例——只缩放数值会让高层失去决策。词缀之间要有**克制关系**，且每 5 局轮换一次池子集，避免 Hades 高 Heat 那种「收窄可用 build」。

成本：12 条规则，多数复用现有 `defense_rate` / 速度 / 灵力参数。`A = 299`。

### P0-3 境界从「数值链」改成「解锁链」｜顺手修掉上一轮的数值红线

| | 改前 | 改后 |
|---|---|---|
| `realm_ratio` | 1.00 → **4.00** | 1.00 → **1.60**（数值只占小头） |
| 每境收益 | 只有倍率 | **3 个新池项**（技能 / 词缀 / 敌人 / 流派 / 道途目标） |
| 钩子总量 | 9 | 27 |

**联动收益（重要）**：这同时解决了 01 §8.1 的红线。

| 口径 | 重算 | 结果 | 与第 9 层血量 4400 比较 |
|---|---|---|---|
| v0.1 全最大 | `(180×4.00+600)×2.5×1.8` | **5940** | ❌ 一击清层 |
| v0.2 全最大（未计塔内折扣） | `(180×1.60+600)×2.5×1.8` | **3996** | ✅ 不再一击清层 |
| v0.2 全最大（满传承塔内 50% 计入） | `(288+300)×4.5` | **2646** | ✅ 约需 2 次命中，保留 Boss 战节奏 |

一个改动同时买到「耐玩」和「数值健康」，优先级最高。代价是「变强」的爽感变弱 —— 列入 Q11 请你拍板。

### P1-4 单局缩短 + 道途目标池

- 保留 9 层完整塔；**新增「速通道途」**（只打 5 层，约 6 分钟），提高「再来一局」率。
- 入塔前选 1 个**道途目标**（池 8 个）：限时 / 无伤 / 禁用某流派 / 只用普攻 / 不取三选一 / 满词缀 / 指定流派 / 低境界挑战。目标给额外道行，且**改变整局的构筑优先级**。
- 层间选择 10 s → 6 s。
- 成本：目标判定逻辑 + UI；不动关卡结构。

### P1-5 无尽天梯 + 道行榜（终局钩子，但有明确失效风险）

通关后开启，层数 n 无限，记录个人最高层。

```
D(n) = min(1.12^(n-1), 12.0)        难度系数（软上限）
M(n) = min(floor((n-1)/5), 8)       质变机制数（每 5 层引入 1 条新敌人行为 / 环境机制）
```

**极值验算**：

| 层 n | 原始 `1.12^(n-1)` | 实际 `D(n)` | `M(n)` | 判定 |
|---|---|---|---|---|
| 1 | 1.00 | 1.00 | 0 | 基线 |
| 10 | ≈2.77 | 2.77 | 1 | 正常 |
| 20 | ≈8.61 | 8.61 | 3 | 正常 |
| 30 | ≈26.75 | **12.00**（封顶） | 5 | 超出部分**不转数值**，转机制 |
| 50 | ≈258 | **12.00**（封顶） | 8（上限） | 纯指数会变成数值海绵，已规避 |

**设计铁律**：`D` 封顶后，难度增长必须来自 `M`（新敌人行为、环境机制、词缀组合），**绝不允许继续加血加攻**。这是从 Diablo 3 / Hades 高 Heat 的公开设计批评里直接拿来的教训。

成本：复用现有关卡模块 + 数值缩放，几乎 0 新增美术。风险：无尽模式是最容易被高估的耐玩手段，若 `M` 做不出来，20–30 层后必然失效 —— 已写入第 6 章风险表。

### P1-6 让随机「可驾驭」

- 每局 **2 次卜卦（重掷）**。
- 三选一强制分层：**1 个稳健项**（补当前 build 短板）+ **1 个赌博项**（高波动质变）+ **1 个随机项**。
- 每个选项显示对当前 build 的**预期 DPS 变化**与**质变触发提示**。
- 原理：Roguelite 的爽点是「用决策驯服随机」，不是被随机支配。

### P2-7 把「肝」健康化：保底进度条 + 可选挑战

| | 改前 | 改后 |
|---|---|---|
| 主线进度 | 1.5% 仙品词条 + 60 次保底 | **道行条**：败 +1 格 / 胜 +2 格，满 10 格**必给 1 个新解锁** |
| 低掉率稀有品 | 主线获取 | 移到**可选挑战**（高天劫词缀 / 无尽塔高层）奖励 |

**铁律**：不要把「肝」放在主线必需路径上。主线永远有看得见的保底，想追极限的玩家自己去可选挑战里肝。

## 6. 新增风险与「不建议做」清单

| 风险 | 说明 | 对策 |
|---|---|---|
| R6 无尽塔数值化失效 | 若 `M(n)` 的机制做不出来，20–30 层后只剩数值海绵 | 把 `M` 列为 P0 交付；做不到就不开无尽模式 |
| R7 词缀收窄可用 build | 高天劫下只有 1–2 套 build 可行，反而降低变化 | 词池每 5 局轮换 + 词缀间设克制关系 + M6 埋点监控 |
| R8 解锁链做成「清单式肝」 | 27 个解锁如果全是数值，仍是 D3 老问题 | 每境至少 2 项是**新玩法**（技能 / 流派 / 词缀），不是属性 |

**明确不建议**（都违背「内容量不大」或会制造疲劳）：

- ❌ 靠加关卡 / 加敌人种类堆时长 —— 直接违背约束。
- ❌ 靠装备数值膨胀 + 无限刷 —— 暗黑大秘境的失败模式，且和境界系统打架。
- ❌ 每日任务 / 签到 / 体力 —— 那是留存手段不是耐玩性，且本项目按 A4 是纯单机。
- ❌ 把低掉率当主要时长来源 —— 疲劳型肝，见第 1 节。
- ❌ 只有数值缩放的无尽模式 —— 见第 2 节反面案例。

**砍需求顺序更新**：P2（图鉴 / 成就 / 第 5 技能）→ P1-4 道途目标池可先只做 4 个 → P1-6 重掷可后置 → **P0-1 / P0-2 / P0-3 不动**（这三条是耐玩性的地基，砍了就回到 D1/D2/D3）。
