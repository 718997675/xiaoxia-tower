## 1. 用户决策（原文口径）

> 「每张卡一张独立插画 我觉得很必要 因为这样 才能突出选卡的重要性, 不能有重复感 这是一种设计」

同轮追加（审美基准）：

> 「之前按照你的提示词生成的 卡片图鉴 那个 就很符合我的审美 就按照 那个为基础 剩余卡片的提示词」

两条合起来定义了本轮目标：**72 张卡画面互不重复，但必须长得像同一张图鉴稿里出来的**。因此 `previews/ui/07-codex-gpt-image2_original.png` 是第一风格基准，不是并列参考之一（详见 §3）。

第 35 轮追加决策（原文口径）：

> 「我本来就是 想让你 一张图里包含多个 卡片图 这样 按照72次 每张12个卡片 6次就可以了 这样也节省gpt-image的额度使用,效果不变, 你只需要给我6组提示词就可以 你自己裁剪」

即 **72 / 12 = 6 次生成**：6 张 1536×1024 拼版 PNG，每张 3 列 × 4 行 = 12 格，固定坐标裁成 72 张单卡原稿。原「72 次、一卡一图 1024×1024」是助手把出图方式定死导致的失误，本轮纠正；**风格基准、72 个唯一母题、16/16 画法样板、不含文字/卡框等规格全部不变**。

这是**设计方向拍板**，不是数值或规则改动。它要解决的问题很具体：层间三选一时，如果三张卡只靠 6 个类别纹样 + 4 种卡框换色，玩家看到的是三张「同一张卡换了颜色」，选哪张都差不多，决策重量感被视觉重复感抵消。独立插画让每张卡在 6 秒窗口里有一眼可辨的身份。

**本轮把「不能有重复感」从形容词变成可复算断言**：72 个母题 / 剪影 / 签名两两不同 ⇒ 任取 3 张候选，签名必互异（见 §4）。

## 2. 必须先讲清的冲突：这是一次规格变更，不是补图

`docs/12-卡牌UI规格.md` §5 是现行冻结口径，原文：

> 「卡面 PNG 不含文字……这样 72 张卡只需要 4 张卡框 + 6 张纹样共 **10 张小图**，换文字不用重出图，也避开 `07` §7.3 已定的『不内置自造像素数字 / R9 字体授权』纪律。」

所以「72 张独立插画」**不是**把欠着的素材补上，而是把「模板复用」改成「一卡一图」。二者冲突，记为 **R57**：

| | 现行冻结 `docs/12` §5 | 本轮决议 |
|---|---|---|
| 插画区 | 24×24 纹样 ×2 = 48×48 居中，6 类共用 | 每卡一张独立母题插画 |
| 美术资源数 | 4 卡框 + 6 纹样 = **10 张** | 10 张 + **72 张插画** |
| 换文案成本 | 0 出图 | 0 出图（插画不含文字，仍复用文字层） |
| 目检/合规负债 | 10 项 | **82 项** |
| 重复感 | 同类别 12 张共用剪影 | 同类 12 张剪影也两两不同 |

**处置口径**：用户拍板的是设计方向，但 `docs/12` 是冻结文档，且 **Q17 未拍板、GUI F5 未跑**，因此本轮**不改写 `docs/12`、不替换 `assets/ui/cards/` 的 10 张冻结卡面、不把任何东西标成已入库**。本轮产物全部是 `待外发 / 未回稿 / 候选规格`。这一步不阻止用户立刻出图——出图是外发动作，入库才是门禁动作。

### 3.1 从该稿逐格提取的视觉 DNA（已写进每段通用规格，中英同版）

| 要素 | 该稿的实际画法 |
|---|---|
| 底 | 实色墨底 **#12161F**（深墨蓝），不是纯黑 #000000、不是亮底 |
| 构图 | **只画一个主体且居中，占 45–60%，四周留 35% 以上空墨底**；16 张里绝大多数是「一个符号直接放在墨底上」 |
| 装饰 | **最多 2–4 枚很小的四角星**零星点缀；放射线 / 速度线只在爆发、冲击、飞行、雷击类母题用 3–5 道 |

### 3.2 16 个画法样板 → 72 张卡（16/16 全覆盖）

该稿 4 行 × 4 列共 16 张示意卡。我把每格的**画法**（不是卡名）提取为 `CODEX_SAMPLES` 的 `r1c1`…`r4c4`，再按母题形态给 72 张卡各绑定一个 `codexRef`：例如 `card_poyun`（一剑裂成两道对称剑光）沿用「金光术」的八角星芒 + 硬边放射线，`card_juling`（击杀魂火汇入阵眼）沿用「聚灵阵」的双层圆环法阵 + 环上八光点，`card_zhuansheng`（灰烬重生）沿用「万劫灭」的火焰包裹人形剪影。

每组提示词的 12 格逐格清单都写：「把 07-codex 原稿附作参考图，沿用第 X 行第 Y 张『示意卡名』的**主体形态与线条密度**，**只把中心母题换成该格母题**，#12161F 墨底 / 大面积留白 / 亮阶硬边高光 / 1px 硬描边保持不变」。样板描述里若提到圆环、背光、星点、放射线，一律按【做减法】规则处理，**不是每格通用装饰**。`docs/card-art-plan.json` 存 `codexRef / codexRefPos / codexRefSample / codexRefTechnique`，`previews/card-art-plan-overview.html` 有独立一列可核对；`--check` 强制 16 个样板全部被引用，**16/16 全覆盖**，不是文字说说。

**风格一致由「第一基准 + 画法样板」保证，差异化由「唯一母题 + 唯一剪影」保证**，两者不冲突：同一套墨底 / 留白 / 细线语汇里换掉中心主体，正是那张图鉴稿自己 16 张卡的做法。

### 3.3 必须避开的坑

`07-codex` 稿里 16 张卡名是「清风诀 / 金光术 / 回春术 / 聚灵阵 / 天雷诀…」，与冻结 72 卡库（剑锋淬砺 / 破云式 / 雷篆重描…）**不是一套**；稿内还自带完整文字与写死数值（获得 15 点灵气、`24 / 72`、灵气 +1、右上数字角标）。按 `docs/12` §5 与 R9，这些示意卡**不得直接当卡面资源**。示意卡名在提示词里**只用于定位格子位置**，绝不作为目标卡名；假数值、整卡外框、右上数字角标、卡名条一律不进插画。72 个母题全部从 `docs/卡牌库.csv` 的效果文案重新派生。

**出图目标是「插画区」不是「整卡」**：卡框与文字由另一层绘制（R9 字体授权未结案）。圆环背光与星点虽属插画区装饰，但**只在母题需要时才画**（见 §3.4 的做减法规则），不能因「不含卡框」的纪律把整个克制感砍掉，也不能反过来把装饰铺满。

### 3.4 第 36 轮风格提取更正（**R59**）

用户把 `07-codex` 原稿重新贴出并说明「我特别喜欢这版风格，我希望按照这版风格来生成，这个提示词之前也是你给我的」。经逐像素比对，用户贴的「卡牌图鉴.png」与 `previews/ui/07-codex-gpt-image2_original.png` **完全一致**（`ImageChops.difference` 的 bbox 为 `None`），确认是同一张稿。

### 3.5 试裁实测：格位漂移确实发生（R58 从推测变成事实）

同一张第 1 组回稿按固定坐标试裁，扫描亮像素密度低谷得到真实行边界 **y = 289/534/779**，与理论 256 / 512 / 768 偏移 **+33 / +22 / +11 px**；列边界 x = 512 / 1024 已在纯黑空隙内、偏移 0。固定裁切下 **12/12 格**上下边缘都有被切断的星芒或圆环（上下边缘亮像素合计 1593），裁后每格顶部/底部出现半颗星。

`tools/split_card_art_sheets.py` 因此新增 `--adaptive`：自动探测真实行 / 列空隙，按实测边界分段取中心 384×256，理论边界已在空隙里就保持不动，**不拉伸、越界补墨底**；报告里 `cropBox` 是标称框、`usedBox` 是实际使用框，`detectedBoundaries` 记录偏移。真实回稿端到端试裁结果：12 张均 384×256、格位与命名全对，上下切边亮像素降到 **585（减少 63.3%）**，12 格圆环与星芒基本完整。固定坐标模式仍保留为默认，映射表 `sheetSpec` 与 72 个 `cropBox` 契约不变。

## 4. OMPC：一卡一母题，可复算的「不重复」

每张卡绑定 5 个字段，全部落在 `docs/card-art-plan.json`：

`motif`（唯一视觉母题）· `motifEn` · `silhouette`（主体剪影）· `composition`（构图键）· `focalBand`（主色段）
→ `signature = motif|silhouette|composition|focalBand`

生成器与全量自检的硬断言：

1. 72 个 `motif` / `motifEn` / `signature` / `silhouette` / `outputName` **两两不同**；
2. 6 类各 12 张，**类内 12 个剪影也两两不同**（防止最常同屏的同类卡撞脸）；
3. 每张提示词都点名同类相邻两张的母题作为「不得画成」的排除项；
4. 72 个签名互异 ⇒ **任取 3 张候选，签名必互异**，三选一同屏不会撞脸。这是「不能有重复感」的机器定义，而不是靠目检感觉。

72 个母题不是随机凑词，逐条来自卡面效果，例如：`card_poyun`「一柄剑裂成两道对称剑光且总光量守恒」（对应「飞剑分裂为 2 道，总伤不变」）、`card_kongzhan`「空盏杯底最后一滴被放大」（对应「灵力 <20% 时伤害 +20%」）、`card_shouzhuo`「空手退让三选一并逐层叠起减伤梯」（对应「放弃本层三选一，此后每层 +4% 减伤」）。

**稀有度不靠插画表达**：4 档仍由卡框色段 + 边框层次 + 角标点数区分，插画不因稀有度变「更华丽」。否则同档 10 张会再次趋同，正好破坏本轮目的。
