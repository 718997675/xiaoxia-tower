# 33 · Boss 远程技能（投射物）接入战斗与第 44 轮边界

> 用户指令：「继续做」。
> 本轮把第 43 轮三阶段里「只改属性、攻击方式没变」的缺口补上——
> Boss 现在会定时释放远程技能：发扇形飞剑弹飞向玩家，玩家可闪避，命中走与近战同一条扣血路径。

## 0. 一句话

第 43 轮让 Boss 有了三阶段（伤害/攻速/移速随血量递增），
但攻击方式仍是「走近了平砍」，和杂兵没有质变；`skill` 真帧只在切阶段时播一下。
用户第 34 轮起的设计诉求是「每个设计点都要突出、不能重复」，Boss 作为战斗高潮更该有专属攻击。
网页验证层（`tools/battle_sim.js`）没有弹幕系统，因此这是 Godot 侧独立落地的表现层增强。

## 1. 改前 → 改后对照（约定②：不原位覆盖）

| 项 | 改前（第 43 轮） | 改后（第 44 轮） |
|---|---|---|
| Boss 攻击 | 只有走近平砍（+阶段属性系数） | 平砍之外，定时发**远程扇形飞剑弹** |
| skill 帧 | 仅切阶段播一次变身 | 继续做变身；远程弹复用 `vfx_flying_sword` 帧（另一套资源） |
| 伤害结算 | 近战内联在 `_tick_enemies()` | 抽成 `_hurt_player()`，近战与投射物**共用**（逐字段不变） |
| 闪避 | 只对近战有效 | 投射物飞行中玩家无敌（闪避/受击无敌）时直接穿过不扣血 |
| 阶段联动 | 伤害/攻速/移速 | 追加：阶段越高弹数越多（1/2/3）、技能 CD 越短（6.0/4.8/3.6s） |
| 快照 | `boss_phase` | 追加 `projectile_count` |

**冻结基线逐字节未动**：`data/buff-card-library.json`、`BattleFormula.gd` 五上界与 9 层表、
`docs/01/11/12` 冻结口径、`assets/ui/cards/` 10 张卡面、`project.godot` 主场景（仍 TowerRun）。
本轮**只改表现层源码**：`RunConfig.gd` / `StageView.gd` / `tools/verify_tower_run.gd`。
远程弹**复用现有 `assets/vfx/frames/vfx_flying_sword_*` 4 帧，未新增任何出图 / 素材**。

## 3. 机制与数值落点（全部 PROPOSAL / 表现层，非平衡值）

| 项 | 值 | 落点 |
|---|---|---|
| 每次弹数 | 阶段 1/2/3 = 1/2/3 | `BOSS_SKILL_SHOTS` |
| 技能 CD（秒） | 阶段 1/2/3 = 6.0/4.8/3.6 | `BOSS_SKILL_CD` |
| 弹速 | 190 px/s | `BOSS_PROJ_SPEED` |
| 弹伤害 | 近战 incoming × 阶段伤害系数 × 0.55 | `BOSS_PROJ_DAMAGE_SCALE` |
| 存活上限 | 3.2 s，飞出逻辑屏自毁 | `BOSS_PROJ_LIFETIME` |
| 扇形张角 | 相邻弹夹角 0.22 rad | `BOSS_PROJ_SPREAD` |
| 首施法延迟 | 开层后 2.5 s | `BOSS_SKILL_FIRST_DELAY` |

- 伤害结算统一：`_hurt_player(raw)` 返回 0=正常 / 1=复活 / 2=死亡，
  近战与投射物共用同一段减伤 → 护盾 → 受击无敌/回灵 → 复活/死亡逻辑（R51 卡牌效果不受影响）。
- 命中判定：投射物与玩家圆形距离 ≤18px；玩家 `invuln>0`（闪避 Space / 避水卡）时穿过不扣血。
- 切层 / `stop()` 清空所有在飞投射物，不跨层残留。
- **非 Boss 零影响**：`skill_cd` 字段只在 Boss 生成时写入；非 Boss 层投射物恒为空、
  `_tick_boss_skills()` 空操作，第 41–43 轮行为逐字段不回退。
