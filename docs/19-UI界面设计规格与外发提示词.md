## 0. 先说清四件事（避免白干）

1. **这批图属于「参考稿」，不是可直接入库的资源。**
   `03` §4 的素材分层矩阵写得很清楚：AI 生成图只用来**拍 Q7 风格锚点 / 做占位**，真正的成品资源走程序化像素链路（`tools/build_icons.py` 之类）。像素风 UI 要求**逐像素可控**（1px 描边、整数放大、24 色不越界），图像模型做不到。所以这批图的价值是**定风格与布局方向**，不是切图入库。
2. **出图顺序：先 ⓪ 风格锚点板，再逐个界面。**
   `03` §8 的协作链路把「拍 Q7 风格锚点」列为整条链路的第一步。风格没定就批量出界面，返工成本最高。
3. **一次只出 1 个界面。** 模型在多界面同图任务里极易串味（按钮串台、文字变成乱码、配色漂移）。
4. **回稿给我 → 我自动核。** `tools/check_ui_art.py` 会检查尺寸、24 色越界、半透明像素、抗锯齿中间色，输出报告（见 §6）。

## 1. 全局风格锚点（所有界面共用的固定前缀）

### 1.1 不可协商的技术规格

| 项 | 规格 | 出处 |
|---|---|---|
| 逻辑画布 | **480 × 270** | `04` §2 / DF-13 |
| 放大倍数 | **整数 4 倍 = 1920 × 1080**（+ letterbox），不做 0.5× 之类小数缩放 | `04` §2 |
| 纹理过滤 | **Nearest 硬边、无抗锯齿、无柔化** | `01` §9 / DF-13 |
| 调色板 | **24 色锁定板**（20 核心 + 4 预留），越界色必须为 0 | `04` §4 |
| 描边 | **1px 纯黑 `#000000` 硬描边**，图标/卡面四周 ≥1px 透明留白 | `07` §4 |
| 半透明 | **必须为 0**；压暗 / 遮罩 / 高亮一律用**实色替换**，不用 alpha 混合 | `12` §4 / `04` §4 |
| 阴影 | 不用 `box-shadow` 模糊；改用**底部 1px 实色基线**表示悬浮 | `12` §4 |
| 位移 | 全部 4 的整数倍友好值，**不做亚像素位移** | `12` §2 |
| 文字 | **不在素材层出文字**；文字由 UI 文字层渲染（本轮出图可带文案做氛围，但入库前要抹） | `12` §2 / `07` §4 |

### 1.3 设计铁律（这一段是整个项目的视觉宪法，别让模型改）

- **类别靠形状，稀有度靠边框层次 + 色段，状态靠角标点阵；颜色永远只做辅助，不是唯一区分手段。**
- 9 个境界压成 **4 段色**：炼气/筑基=墨亮 `#4A5568`、金丹/元婴=青玉 `#5FA8A0`、化神/炼虚=紫 `#8A6FC4`、合体/大乘/渡劫=金 `#D9A441`；段内靠**纹样 1–9 道**和数字区分。
- 图标外框 6 类剪影互不相同：技能=八角切角框、流派=正圆框、词缀=菱形框、境界=横向卷轴框、装备=盾形框、灵韵=六边框。
- 8 个技能特效**形状与方向两两可区分**：横弧（剑气斩）/ 斜三剑（御剑诀）/ 纵雷（引雷符）/ 方符（纸傀术）/ 圆火（三昧丹火）/ 空心环（回春诀）/ 短扇波（破山拳罡）/ 六边罩（金刚不坏）。
- 4 流派符号与 4 件武器挂件**同形**：剑 / 符 / 丹炉 / 拳套。

### 4.1 机器：一条命令

```bash
python3 tools/check_ui_art.py previews/ui/你的图.png
```

检查项：

| 检查 | 判定 | 依据 |
|---|---|---|
| 尺寸 | 必须是 **480×270 的整数倍**（1920×1080 = 4×）；非整数倍直接 FAIL | `04` §2 |

| 抗锯齿中间色 | 同一 3×3 邻域内出现大量既非调色板色、又非其邻色的「第三色」→ WARN（提示模型画了柔边） | `04` §4 |
| 纯色大面积 | 非背景区域出现 > 25% 的单一纯白像素 → WARN（多用了 `#FFFFFF`） | `04` §4 |
