# 第 46 轮 · 战斗打击感反馈（Godot 表现层）

## 一句话

前几轮把 Boss、杂兵的机制做厚了，但命中反馈一直停留在「飘一个数字 + 一个通用 hit 特效」，
战斗缺少打击感。本轮补上屏幕震动、连击里程碑、暴击/击杀差异化飘字——全部纯表现层，
不改伤害 / HP / CD / 命中判定任何数值。

## 做了什么

### 三项反馈（RunConfig 常量，PROPOSAL，非冻结、非平衡结论 R51）

1. **屏幕震动**：暴击 / 击杀 / 玩家真扣血时，给一台专用 `Camera2D` 的 `offset` 一个随机抖动，
   按衰减率回落（约 0.2 s 停）。幅度：暴击 2.4px、击杀 3.6px、受击 2.0px，上限 6px 防止叠加失控。
   - 关键：相机 `position` 固定在逻辑屏中心，**只改 offset**；所有战斗坐标是 `StageView` 局部坐标，
     相机偏移不影响移动 / 命中 / 投射物任何判定。
   - 护盾吸收、闪避不触发受击震动（与真实扣血路径一致）。
2. **连击里程碑**：`combo`（0~1.5 小数）跨过 0.5 / 1.0 / 1.5 三档时，各发一次
   `combo_milestone` signal + 飘字「连击·起 / 势 / 极」，HUD info 条染金并追加档位标签。
   用 `combo_tier` 记录已触发档位，只升不重复；新局 `reset_player()` 清零。
3. **暴击 / 击杀飘字**：暴击伤害数字字号从 11 放大到 16（颜色/文案不变）；击杀额外飘一个
   「斩」字。都只改字号与提示文案，不改伤害结算。

### 实现落点

- `scripts/StageView.gd`：
  - `_ready()` 建 `ShakeCamera`（Camera2D）；`_process()` 按 `HIT_SHAKE_DECAY` 衰减 offset。
  - `_trigger_shake()`（取较大幅度并钳上限）、`_check_combo_milestone()`（跨档发 signal）。
  - `_cast()` 命中段：暴击放大飘字 + 震动 + 计数；击杀「斩」+ 震动 + 计数；combo 增长后查里程碑。
  - `_hurt_player()`：仅 `taken>0`（真扣血）时触发受击震动。
  - `_float_text()` 加可选 `font_size` 参数（默认 11 与第 41 轮一致）。
  - `reset_player()` 重置 `combo_tier` / 抖动；`snapshot()` 暴露 `shake_amount` / `combo_tier` /
    `feedback_stats` 供 HUD 与 headless 校验。
  - debug 接口：`debug_shake()` / `debug_tick_shake()` / `debug_trigger_shake()` / `debug_set_combo()`。
  - 顺带修正 `debug_mob_attack()` 近战分支：补上与真实 `_tick_enemies` 一致的 invuln 闪避检查
    （此前 debug 接口绕过 invuln，与真实路径不符；本轮为验证受击震动而对齐）。

### headless 验证（tools/verify_tower_run.gd）

可玩闭环从 45/45 扩到 **51/51**（原 45 项不回退 + 新增 6 项）：

- `feedback_camera_ready`：震动相机存在、初始 offset 归零
- `feedback_shake_then_decay`：触发幅度 3.6 → offset 非零 → 衰减归零
- `feedback_hurt_shake`：真扣血触发 hurt 震动，闪避不触发
- `feedback_combo_milestones`：跨三档发 3 次 signal、combo_tier=2
- `feedback_milestone_once`：同档重设不重复触发
- `feedback_stats_observable`：反馈统计字段齐备

## 诚实边界

- 本轮是**纯表现层**，不改变任何战斗数值与判定；headless 验证的是「状态量按预期变化」，
  不是画面本身。屏幕抖动的观感、飘字是否成字、HUD 高亮是否放得下，仍需 F5 目检。
- **R56 逐 tick 仍未跨端对齐**：网页验证层没有震动/飘字反馈系统，这是 Godot 独有表现层增强，
  不宣称「网页测过 = Godot 一致」。
- **R68（本轮新增）**：震动幅度 / 衰减 / 连击阈值是拍脑袋的表现层参数，未经手感实测；
  连续击杀时多次震动取较大值（钳上限），实际观感可能偏抖或偏弱，需 F5 调节。
- 全部 PROPOSAL，非冻结规格、非平衡结论（R51）。

## 复现

用本机 Godot 4.7.2 可执行文件（路径按机器实际填写，不写死在文档里）：

```
<Godot> --headless --editor --quit
<Godot> --headless --path . --script res://tools/verify_tower_run.gd
python3 tools/final_selfcheck.py
```
